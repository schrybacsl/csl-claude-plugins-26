# Weekly Field Report (FR #nn)

Skeleton for the weekly field report in the shape of Brown University Health FR #16 (F. MacPherson, Senior PM), which seeded the field-report module of the Brown Health dashboard. One report per project per week; daily Clerk of the Works notes roll into it. One populated example row per table shows the level of specificity; the example content is illustrative for a phased healthcare renovation and is not a client record. Variables in `<angle brackets>` change every issue. Number and file name per `csl-design-construction-oversight` Section 4: `FR #<nn>`, file `CSL-<PROG>-FR-<nnn>_<yyyy-mm-dd>.pdf`.
