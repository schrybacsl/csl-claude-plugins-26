# CSL Business Development

Pursuit and qualification skills for Marketing, BD, and pursuit teams. Requires `csl-core`.

## Skills

| Skill | Purpose |
|---|---|
| `csl-bd-pursuits` | Solicitation screening, go/no-go, SOQ and RFP responses, compliance matrices, LOE proposals, capability statements |
| `csl-projects` | CSL project portfolio by sector (public website, February 2026) for qualifications |

## Commands

`/csl-business-development:go-no-go`, `:compliance-matrix`, `:soq`, `:loe`

## Rules that matter most here

Qualifications cite only portfolio projects; values not in the portfolio are `[PLACEHOLDER]` for Marketing. Active engagements not on the website are anonymized unless the PX confirms client permission. Rates and fees never appear in a technical volume. Every submission is reviewed by the responsible PX before it leaves CSL.
