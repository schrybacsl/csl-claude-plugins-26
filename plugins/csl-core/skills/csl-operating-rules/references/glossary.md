# Glossary

Terms the agent will meet in CSL owner's-representative work, with the meaning used on CSL programs. Where a term is engagement-specific it is marked (W77), (BUH), etc. Spell out on first use in client-executive documents.

## Roles and contracting

| Term | Meaning |
|---|---|
| Owner's Representative / Owner's Rep | Consultant acting for the owner across design, procurement, construction, and turnover; no design or construction liability of its own; protects owner budget, schedule, risk, scope |
| OPM | Owner's Project Manager; Massachusetts public-construction term for the same role (M.G.L. c.149 §44A½ requires one above $1.5M) |
| Capital Program Executive | Senior owner-side role across a portfolio of projects rather than one project |
| CM at Risk (CMAR / CM@R) | Construction manager holds the trade contracts and a GMP; owner's rep reviews GMP, buyout, and change orders |
| CM-Build | Owner-side term (DASNY) for CM at Risk with early involvement |
| Design-Bid-Build (DBB) | Sequential delivery; lump-sum general contractor |
| Design-Build (DB) | Single entity for design and construction |
| GMP | Guaranteed Maximum Price |
| A/E | Architect/Engineer of record |
| FM | Facilities Management (client's operator, e.g., Emcor/HaSe at W77) |
| CRE | Corporate Real Estate (ASML's owning organization for W77) |
| CoE | Center of Excellence (ASML building automation) |
| IFM 2.0 / IMF 2.0 | Integrated facilities management contract transition at W77 (award expected end Sept 2026); also "R&P provider" (repair and preventive maintenance) |
| SOQ | Statement of Qualifications (response to an RFQ) |
| RFQ / RFP / ITB | Request for Qualifications / Proposals; Invitation to Bid |
| LOE | Level of Effort (proposal for hours/fee against a defined scope) |
| MOU / NCP / DOE | Memorandum of Understanding; NATO Commercial Partner application; Declaration of Eligibility (NATO pursuit) |

## Program controls

| Term | Meaning |
|---|---|
| Baseline | The approved schedule/budget the program is measured against; changes only by written re-baseline |
| Re-baseline | Formal reset of the baseline, minuted, with the delta recorded |
| Look-ahead | Forward view of the coming period's commitments (one-week on W77; typically two or three weeks in construction) |
| Float | Schedule slack before a delay affects the critical path |
| Critical path | Longest chain of dependent activities; zero float |
| Constraint | Picklist reason a task cannot proceed (W77 values: Seasonal Weather Dependent; Access Limitations/Share Corridor; CapEx/Funding Gate; Long Lead Time; Operations Blackout; Outage Scheduling Utility Tie-in; Safety EH&S Limitation; Permit Regulatory; Dependency Enabler Pending) |
| Bow wave | Work deferred toward the end of a program (W77: 102 projects deferred to 2032 at the March 2026 baseline) |
| FMEA | Failure Mode and Effects Analysis |
| RPN | Risk Priority Number = Severity × Occurrence × Detection (1–10 each; max 1,000). W77 critical threshold ≥ 700 |
| E-GRP | Equipment group classification on the W77 roadmap (17 groups: AHU, Fan, Electrical, Roof, Chillers, Tower Cooling, Boiler, Facility, CDA, Mechanical Piping, RODI, Sanitary, Nitrogen, Vacuum, Fire, Gas, PH) |
| Taxonomy | W77 roadmap system classification (01 Civil; 02 Architectural; 03 HVAC; 04 Water & Other Liquids; 05 Gases; 06 Electrical; 09 Safety) |
| Health | Tracker status color (Green / Yellow / Active / Pending on W77 roadmap; Green / Blue on CSL tasks) |
| RAG / tier | Red / Amber / Green rating assigned to every finding |
| Past-target | A mitigation row whose target date has passed without closure (W77 mitigation sheet KPI) |
| Frozen tracker | A sheet unchanged across two or more consecutive pulls; a data-governance finding |
| Silent lapse | A milestone date passed with no status change |
| Work done, no record | Field activity with no matching permit or tracker row |
| Anchor row | A tracker row whose closure the week's plan is built around |
| Docket | The list of next actions with owners and dates at the end of a report |
| Perfect week (permits) | Every permit that started this week had all gates cleared before start |
| Gate (G-nn) | A numbered condition that must be satisfied before a program step proceeds (W77 Planon EWO register) |
| Open confirm | A question put to the client in writing that blocks or qualifies a deliverable until answered |

## Commercial

| Term | Meaning |
|---|---|
| CAPEX / OPEX | Capital versus operating expenditure |
| CAAR | Capital Asset Appropriation Request (ASML). Not "CARR" |
| CARR (BGP) | Capital Appropriation Request Review tracker in the W77 BGP workspace (distinct from CAAR) |
| BGP | Building Governance Process (ASML tollgate process) |
| PDS / URS | Project Definition Sheet / User Requirements Specification (ASML intake documents) |
| PMO / IMT / REDM | Project Management Office; Infrastructure Management Team; the ASML review meeting cadence to which strategies are taken (REDM 10/01/26 for the IRO strategy) |
| PO | Purchase order; on the W77 mitigation sheet, step 10 of the lifecycle and written back to the row |
| Proposal-to-PO pipeline | Tracking a scope from priced proposal through approval to PO issuance |
| Change order (CO) / PCO / CCD | Approved change; proposed change order; construction change directive |
| Pay app / requisition | Contractor's periodic payment application (AIA G702/G703) |
| Retainage | Amount withheld from each payment until completion |
| Contingency | Owner's or CM's reserve; drawn only by documented change |
| EVM / PV / EV / AC | Earned value management; planned value, earned value, actual cost |
| Burn rate | Spend per period against plan |

## Facilities and systems (as used on W77 and similar sites)

| Term | Meaning |
|---|---|
| CHW / CDW / HHW / STM | Chilled water; condenser water; heating hot water; steam |
| PCW / PPCW | Process cooling water; primary process cooling water |
| ST CHW/PCW | Site chilled-water / process-cooling-water systems (the mitigation sheet's scope) |
| Delta-T | Supply-to-return temperature difference; low delta-T is the common symptom pathway in WS-02 |
| POU | Point of use (filters, cabinets) |
| AHU / RAH / MAU / ERV | Air handling unit; return air handler; makeup air unit; energy recovery ventilator |
| VFD | Variable frequency drive |
| HX / plate-and-frame | Heat exchanger replacing 3-way mixing valves (WS-22.08) |
| RPZ / BFP | Reduced-pressure-zone backflow preventer (Watts LF009 at W77 NE entrance, coded BFP01) |
| CDA / N2 / RODI / VAC / SPG | Compressed dry air; nitrogen; reverse-osmosis deionized water; vacuum; specialty gases |
| BMS / BAS | Building management / automation system |
| CTRW | Cooling tower / test-rig water telemetry program (rigs TR7, TR2, TR5) |
| LCWC / RCWC | Local / remote cooling water circuit readings on DUV tools; "Bottom" (zero flow) is a tool-down signal |
| DUV / EUV / NXE / NXT | ASML lithography platforms present at Wilton |
| UT / MTI | Ultrasonic thickness testing; the testing vendor on the CHW wall-loss report |
| ASME B31.9 / API 579-1 (FFS-1) | Building services piping code; fitness-for-service standard |
| SIPP | Safety in Process Planning: contractor work permit and hazard-coordination system (proprietary CSL process); permits carry gates |
| LOTO | Lockout / tagout |
| ICRA | Infection control risk assessment (healthcare projects) |
| OFOI / CFCI / VFCI | Owner-furnished owner-installed; contractor-furnished contractor-installed; vendor-furnished contractor-installed (equipment planning) |

## Asset data / CMMS

| Term | Meaning |
|---|---|
| CMMS | Computerized maintenance management system (Planon at ASML; CHAMPS legacy) |
| Planon / CHAMPS | ASML's current CMMS and the legacy system being migrated from |
| GFC | Functional code (ASML naming scheme; `ASML_WLT_077_<UNIT>` under the 08/24/26 rulings) |
| PML | Parent Master List: the asset hierarchy for a building |
| Standard asset / asset type | Planon classification of what an asset is (distinct from its functional code) |
| Taxonomy (Planon board) | Numbered system families on the PML whiteboard (1 Electric, 2 Loops-CHW, 3 HVAC, 4 Roof, 5 Water, 6 Gases; 6A CDA/X, 7 RO/DI, 8 Elevator, 10 Crane, 11 Sewage, 12 Dock, 13 Doors, 14 Fire, 15 Life Safety) |
| Upload sheet | The client-template data file used to bulk-import assets |
| New Asset Form | Intake form for adding assets outside the bulk upload |
| QR tagging | Physical labeling of assets with codes; gated on code stability |
| Walk-down | Field verification of asset existence, nameplate data, and tags |
| Tag collision | Two physical assets sharing one field tag (W59 TCWP-1) |
| Double-listing | One physical asset appearing as two records (SE05–10 vs Smoke Exhaust 05–10) |
| Cost center / space | Planon record fields required for work-order routing |

## Reporting

| Term | Meaning |
|---|---|
| WKR-nnA/B/C/D | CSL weekly report editions (Look-Ahead, Mid-Week, End-of-Week, supplement) |
| PLN-SUM / PLN-EWO | Planon weekly critical summary; Planon end-of-week edition with gate register |
| Command view | Executive header view of a dashboard built for a named stakeholder (Gannon Command, Koning) |
| Options menu | Checklist of KPI modules a stakeholder selects from for a custom view (modules coded A1…E6) |
| Report factory | The Python pipeline that pulls sheets and renders the branded PDFs |
| Chart library | Reusable slide/figure set for weekly reporting |
| Source note | The list of pulls (sheet, ID, timestamp) on a report |
| Record correction | Same-day written reply correcting a counterpart's minutes or recap |
| Transcript audit | Line-by-line comparison of issued minutes against the meeting transcript |
